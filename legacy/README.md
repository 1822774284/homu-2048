# legacy —— 早期的尝试，留作对照

这些文件**不属于当前版本**，只是开发过程中的原型与调参台，留在这里方便回看当时怎么试的。

| 文件 | 是什么 | 为什么不在主线 |
| --- | --- | --- |
| `prototype-2d.html` | 最早的“俯视倾斜 2D”原型：4×4、CSS 3D 倾斜板、单步撤销 | 被 `game2d.js` 的正式实现取代 |
| `cube.html` | 静态线框格 + 可移动方块对象、相机、坐标轴、分层的早期 3D 版本 | 被 `index.html` + `game3d.js` 的正式实现取代 |
| `cube3d.html` | 材质调参台：`?cfg=<JSON>` 可复现任意一组参数 | 调参完成后参数已固化进 `game3d.js` 的 `LOOK` |
| `panel-drag.js` | 调参台用的拖动面板 | 只服务 `cube3d.html` |
| `tuned-*.json` | 调参台保存的三组材质参数 | 同上 |

`keycheck.py`（真实窗口按键回归）已删除：它依赖项目外的 `auto` 模块，且已被 `probe-cdp.mjs` 的无头方案完全取代。
